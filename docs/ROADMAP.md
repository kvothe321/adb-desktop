# Roadmap

The planned features are in place. What comes next, highest priority first:

1. **Screen**: mirror the device screen live in the app.
2. **Shell**: wide characters and input methods, so CJK text and emoji line up and can be typed.
3. **Logcat**: reconnect on its own after a stream fails, without repeating lines already shown.
4. **Apps**: react to package changes as they happen instead of checking every few seconds.
5. **Build**: move to detekt 2 once it is stable, which removes the last Gradle deprecation warning.
